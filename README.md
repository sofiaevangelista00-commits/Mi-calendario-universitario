# Organizador Universitario Pastel 🌸

Una aplicación web interactiva diseñada para estudiantes universitarios. Permite gestionar materias, entregas de trabajos prácticos, exámenes, horarios y apuntes con una interfaz en tonos pastel.

## Características

- 📅 **Calendario Mensual**: Visualización de fechas límite de entrega y parciales.
- 📚 **Gestión de Materias**: Organización por materias con colores pastel personalizados, profesores y aulas.
- ✅ **Lista de Tareas Interactiva**: Subtareas, prioridades y estado de completado.
- 📝 **Bloc de Apuntes**: Guardado rápido de notas universitarias.
- 📱 **Diseño Responsivo**: Adaptado para usar en computadoras y teléfonos móviles.
